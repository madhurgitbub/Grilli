# Grilli - Luxury Dining & Modern Restaurant Web Application 🍽️✨

**Grilli** is a premium, fully responsive, and feature-rich front-end website designed specifically for fine dining, luxury restaurants, and modern culinary businesses. Crafted with a mobile-first approach using clean **HTML5**, modern **CSS3**, and **Vanilla JavaScript (ES6+)**, Grilli provides an immersive visual experience with smooth animations, dynamic interactive components, and intuitive online table reservation workflows.

🚀 **Live Demo:** [grilli-indol.vercel.app](https://grilli-indol.vercel.app)

---

## 🌟 Detailed Features Breakdown

### 📱 1. Mobile-First & Fully Responsive Layout
* Seamlessly adapts across Desktop (1400px+), Tablet, and Mobile screens.
* Flexible layout architecture powered by CSS Grid and Flexbox for optimal component alignment.

### 🎨 2. Immersive Visuals & Interactive UI
* **Hero Banner Slider:** Dynamic visual showcase highlighting special signature dishes and promotional offers.
* **Header & Navigation:** Sticky top header with background blur, active section indicators, and responsive mobile overlay menu.
* **Parallax Scrolling Effects:** Enhances storytelling through depth and high-definition food photography.
* **Custom Back-to-Top Button:** Enhances navigation for lengthy content scroll setups.

### 🍽️ 3. Categorized Menu Showcase
* Organized culinary listings (Starters, Main Courses, Drinks, Desserts).
* Displays detailed dish descriptions, key ingredients, special dietary tags (e.g., Seasonal, Chef Special), and transparent pricing.

### 📅 4. Interactive Reservation System
* User-friendly online table booking form capturing essential customer details:
  * Number of guests
  * Preferred date & time slot
  * Special dietary requests or instructions
* Integrated client-side form validation for a smooth booking submission flow.

### 👨‍🍳 5. Brand & Storytelling Components
* **About Us Section:** Highlighting restaurant heritage, culinary philosophy, and hygiene standards.
* **Chef Highlights:** Profiles of master chefs featuring signature creations.
* **Customer Testimonials:** High-impact review carousel demonstrating social proof and guest satisfaction.
* **Footer & Contact Details:** Displays business operating hours, location map integration, social media channels, and newsletter subscription form.

---

## 🛠️ Tech Stack & Architecture

* **HTML5:** Semantic structural components (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) to ensure high accessibility (a11y) and optimal SEO ranking.
* **CSS3:** Custom design system using CSS variables (design tokens for typography, colors, spacing), Flexbox, CSS Grid, media queries, and smooth keyframe animations.
* **JavaScript (Vanilla ES6+):** Pure JavaScript without external dependencies for lightweight page performance:
  * Custom DOM manipulation scripts for menu switching and dynamic toggles.
  * Event-driven header scroll effects and mobile navigation state management.
  * Interactive image slider logic.
