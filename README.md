# Grilli 🍽️✨

**Grilli** is a fully responsive, modern website designed for luxury dining and modern restaurants. Built using clean HTML5, CSS3, and modern JavaScript, it delivers a seamless user experience across mobile, tablet, and desktop screens with smooth animations, interactive menus, and reservation options.

🚀 **Live Demo:** [grilli-indol.vercel.app](https://grilli-indol.vercel.app)

---

## 🌟 Features

* **Fully Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, Desktop) following a mobile-first approach.
* **Interactive UI/UX:** Smooth scrolling, dynamic navbar, hero sliders, and micro-interactions for elevated engagement.
* **Online Table Reservation:** Interactive reservation form for quick booking requests.
* **Special Menu Showcase:** Categorized menu items featuring pricing, ingredients, and visual presentation.
* **Testimonials & Chef Highlights:** Dedicated sections to showcase culinary offers and customer reviews.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessible markup.
* **CSS3:** Custom styling, Flexbox/Grid layouts, and CSS animations.
* **JavaScript (Vanilla ES6+):** DOM manipulation, navbar toggles, and dynamic UI logic.
